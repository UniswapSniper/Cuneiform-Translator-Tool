# Datasets & provenance

Track all data sources, licenses, and decisions here.

## Public sources

### CDLI (Cuneiform Digital Library Initiative)
- **URL**: https://cdli.ucla.edu/
- **License**: CC0 1.0 Universal (Public Domain)
- **Content**: ~500k+ tablets, images, transliterations, metadata
- **Scope for MVP**: Ur III administrative texts (well-documented, high-quality images)
- **Status**: not yet ingested

### ORACC (Open Richly Annotated Cuneiform Corpus)
- **URL**: http://oracc.museum.upenn.edu/
- **License**: CC0 1.0 Universal (with attribution requested)
- **Content**: transliteration corpora (not aligned to images)
- **Use case**: validation of transliterations, lexical lookup
- **Status**: not yet integrated
